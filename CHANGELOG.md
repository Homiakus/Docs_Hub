# История изменений (CHANGELOG)

Все заметные изменения проекта Docs_Hub фиксируются в этом файле в соответствии с принципами [Keep a Changelog](https://keepachangelog.com/).

## [v0.5.0] - 2026-08-22

### Добавлено
- **Мировая документация**: Полностью обновлён `README.md` с архитектурной схемой, бейджами, подробной матрицей конфигурации и двуязычным обзором.
- **Новые архитектурные решения (ADR)**: Добавлены ADR 0001 (SQLite WAL), ADR 0002 (Markdown & XSS Security Pipeline), ADR 0003 (RBAC & Spaces), ADR 0004 (Fluid Responsive Design System).
- **Спецификация API**: Создан документ `docs/API.md` с подробным описанием всех REST-эндпоинтов, форматов запросов и ответов.
- **Руководство по развёртыванию**: Создан документ `docs/DEPLOYMENT.md` с инструкциями для Docker Compose, systemd, Caddy, Nginx и сценариями резервного копирования.
- **CI/CD Автоматизация**:
  - Обновлён `.github/workflows/ci.yml` с поддержкой сканирования уязвимостей `govulncheck`, матрицы тестов и кеширования.
  - Добавлен рабочий процесс `.github/workflows/release.yml` для автоматической кросс-платформенной компиляции бинарных файлов (Linux, Windows, macOS для x86_64 и ARM64).

### Изменено
- Актуализирован `docs/ROADMAP.md` с разделением на выполненные этапы и планы развития v1.0.

## [v0.4.0-alpha.2] - 2026-07-18

### Добавлено
- Однопанельный мобильный редактор с переключением «Редактор / Предпросмотр», сворачиваемыми свойствами и закреплённой панелью сохранения.
- Полноценный PDF.js viewer с canvas-рендером, навигацией по страницам, масштабом, текстовым слоем и поиском внутри документа.
- Touch-жесты и клавиатурное управление графом: pinch-to-zoom, горизонтальное перемещение, стрелки и управление масштабом.
- Кросс-браузерная матрица Playwright для Chromium, Firefox и WebKit на desktop, tablet и mobile.

### Изменено
- Мобильный breakpoint расширен до 900 px, чтобы iPad Mini и узкие планшеты использовали drawer-навигацию и одноколоночные рабочие области.
- Интерактивные элементы увеличены до 44 px на touch-устройствах; добавлены safe-area, dynamic viewport и компенсация экранной клавиатуры.
- Улучшены адаптивность таблиц, прокрутка шаблонов, доступность dialog/drawer и читаемость статусов в светлой теме.

### Исправлено
- PDF больше не открывается в ограниченном iframe без собственной навигации и мобильного управления.
- Граф больше не блокирует вертикальную прокрутку страницы одним касанием и сохраняет читаемый минимальный масштаб.
- Автотест PDF теперь загружает корректный документ и ждёт фактического canvas-рендера.

### Безопасность
- HTTP test harness генерирует уникальные пароль администратора и session secret для каждого запуска вместо фиксированных значений.

## [v0.4.0-alpha.1] - 2026-07-18

### Добавлено
- Новый адаптивный UI: application shell, dashboard, reader, editor, поиск, пространства, граф, PDF viewer и admin workspace.
- Доступные command palette и конструктор Markdown-таблиц с клавиатурной навигацией и focus management.
- Полный workflow документов от черновика до архива с атомарными переходами и аудитом.
- Фильтры поиска по пространству и статусу, шаблоны документов и функциональная загрузка PDF.
- Playwright quality gate для desktop/tablet/mobile и accessibility-проверок в CI.

### Исправлено
- Исправлены пути импорта CSS-модулей и восстановлено покрытие всех UI-компонентов стилями.
- Автосохранение принимает созданный сервером ID, обновляет hidden state и предотвращает дублирование новых черновиков.
- `lock_version` теперь проверяется и увеличивается атомарно; stale write возвращает `409 Conflict`.
- Выбранное пространство, классификация и язык сохраняются вместе с документом.
- FTS5 индекс пересоздан как обновляемый индекс и синхронизируется при ручном и автоматическом сохранении.
- Demo seeder переведён на совместимый Argon2id-хеш и настраиваемый `DEMO_PASSWORD`.
- Черновики и непубличные workflow-статусы исключены из поиска, графа, backlinks, activity и файлов для читателей без доступа.

### Безопасность
- Проверка прав добавлена в autosave и workflow endpoints.
- PDF и медиа проходят проверку MIME/расширения и наследуют ACL связанного документа.
- Same-origin framing разрешён только для защищённого встроенного PDF viewer.
