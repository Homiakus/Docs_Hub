## 1. Сводная оценка соответствия (Audit Scorecard)

| Направление аудита | Текущий статус | Оценка (1–10) | Ключевые выявленные несоответствия |
| :--- | :--- | :---: | :--- |
| **1. Хардкоды цветов и стилей** | ⚠️ Найдены хардкоды | **6.5 / 10** | Прямые hex-коды (`#fff`, `#17172d`, `#454955`, `#111426`), градиенты `#7373e8` $\to$ `#4c4cc7`, инлайн-тени. |
| **2. Типографика (Swiss Grotesk)** | ⚠️ Консервативная | **6.0 / 10** | Заголовки слишком мелкие (`clamp(1.75rem, 3vw, 2.35rem)`), отсутствует монументальный display-скейл, нет отрицательного трекинга на H1. |

| **4. Отказ от Card Soup** | ❌ Card-heavy паттерны | **4.5 / 10** | Метрики завернуты в `.metric-card` с разноцветными иконками; списки документов оформлены как плавающие карточки со скруглениями. |
| **5. Монохромность палитры** | ⚠️ Пестрота акцентов | **6.0 / 10** | Одновременное использование синего, янтарного, фиолетового и зеленого цветов (`metric-blue`, `metric-amber`, `metric-violet`, `metric-green`). |
| **6. Микротипографика и Координаты** | ⚠️ Частично | **6.5 / 10** | Есть `.eyebrow`, но отсутствуют системные индексы секций (`01`, `02`), локальное время, координатные метки. |
| **7. Motion & Easing Curves** | ⚠️ Стандартный ease | **7.0 / 10** | Используется `ease` и `140ms` вместо фирменного плавного `cubic-bezier(0.22, 1, 0.36, 1)` с каскадным staggered появлением. |

## 3. Анализ соответствия эстетике ORGNZM (Anti-Pattern Breakdown)

### 3.1. «Card Soup» vs. Швейцарская открытая сетка

**Текущее состояние**:
- Дашборд состоит из 4 карточек `.metric-card` с серыми рамками, тенями и цветными иконками.
- Списки документов завернуты в отдельные боксы `.doc-card` со скруглением $12\text{px}$.

**Трансформация в ORGNZM**:
```text
БЫЛО (Обычный SaaS):
┌──────────────┐ ┌──────────────┐ ┌──────────────┐ ┌──────────────┐
│ [◷] 14       │ │ [✓] 6        │ │ [▦] 4        │ │ [≡] 128      │
│ Черновики    │ │ На проверке  │ │ Пространства │ │ Статей       │
└──────────────┘ └──────────────┘ └──────────────┘ └──────────────┘

СТАЛО (ORGNZM Editorial):
┌────────────────────────────┬────────────────────────────┬────────────────────────────┬────────────────────────────┐
│ 01                         │ 02                         │ 03                         │ 04                         │
│ 128                        │ 14                         │ 06                         │ 04                         │
│ TOTAL ARTICLES             │ DRAFTS IN PROGRESS         │ REVIEW QUEUE               │ ACTIVE WORKSPACES          │
└────────────────────────────┴────────────────────────────┴────────────────────────────┴────────────────────────────┘
```
- Числа выводятся размером $48\text{--}64\text{px}$ с тонкими вертикальными разделителями $1\text{px}$ (`--line-hairline`).
- Никаких цветных подложек и скруглений.

### 3.2. Списки документов: Карточки $\to$ Editorial Rows

**Трансформация**:
Вместо изолированных плавающих карточек список документов выстраивается в элегантные горизонтальные строки:
```text
┌────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ 01  STORAGE PERSISTENCE ARCHITECTURE             [Engineering]    Updated 2h ago                →      │
├────────────────────────────────────────────────────────────────────────────────────────────────────────┤
│ 02  OIDC IDENTITY PROVIDER SPECIFICATION         [Security]       Updated Yesterday             →      │
├────────────────────────────────────────────────────────────────────────────────────────────────────────┤
│ 03  KNOWLEDGE GRAPH TOPOLOGY                     [Core Wiki]      15 Jul 2026                   →      │
└────────────────────────────────────────────────────────────────────────────────────────────────────────┘
```
- При наведении строка плавно подсвечивается (`--bg-elevated`), стрелка $\to$ сдвигается на $+6\text{px}$ с кривой `cubic-bezier(0.22, 1, 0.36, 1)`.

### 3.3. Типографика Hero и Заголовков

**Текущее состояние**:
`h1` в дашборде: `font-size: clamp(1.75rem, 3vw, 2.35rem); line-height: 1.12;`

**Трансформация в ORGNZM**:
- Заголовок Hero: `font-size: clamp(42px, 6.5vw, 96px); line-height: 0.95; letter-spacing: -0.038em; font-weight: 750;`
- Намеренные переносы строк и воздух вокруг ключевого стейтмента.
- Микро-лейбл сверху: `01 / REPOSITORY OVERVIEW`.

## 4. План устранения и рефакторинга (Actionable Roadmap)

1. **Фаза 1: Ликвидация хардкодов в CSS и JS**
   - Заменить все прямые цвета (`#fff`, `#17172d`, `#454955`, `#111426`) на токены из `tokens.css`.
   - Убрать радужный градиент из `.brand-mark` в пользу чистого монохромного знака.
2. **Фаза 2: Рефакторинг сетки метрик и списков**
   - Перевести `.metric-grid` на открытую типографическую структуру с 1px hairline разделителями.
   - Заменить `.doc-card` на горизонтальные интерактивные `.editorial-row` с индексами `01`, `02`.
3. **Фаза 3: Внедрение монументальной типографики**
   - Подключить шкалу `clamp(42px, 6.5vw, 96px)` для главных заголовков с отрицательным трекингом `-0.038em`.
   - Добавить системные координаты (`INDEX / 01`, `LOCAL TIME`, `STATUS`).
4. **Фаза 4: Доводка моушн-дизайна**
   - Перевести все ключевые переходы на кривую `cubic-bezier(0.22, 1, 0.36, 1)`.
   - Добавить каскадное появление строк при загрузке (Staggered reveal).
